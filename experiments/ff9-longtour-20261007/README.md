# FF9 · 从天空到王城 · 2026-10-07

目标：约一分钟，镜头从空中向下，迎向飞空剧场，下降到长街，沿街浏览，最终展示王城。

沿用已认可的 B 配方：实际 3D 镜头 → Qwen-Image-2.1 美术润色 → H3 FL2VA fp8 + Turbo8。分辨率 864×480、24fps。所有模型推理复用 4090 GPU0 / 8188，串行运行，不启动/停止共享服务。

## 镜头

1. 0–10 秒：高空迎向木质飞空剧场，靠近船首；5 秒处有中间关键帧。
2. 10–20 秒：从船首下方掠过，镜头下降、俯向街口；15 秒处有中间关键帧。
3. 20–30 秒：进入实际工坊街，浏览前半段店铺。
4. 30–40 秒：沿同一条路浏览后半段店铺，接近皇家石拱门。
5. 40–50 秒：进入喷泉广场，保持原布景与街坊。
6. 50–60 秒：上升并抬头，最后完整展示王城与剑塔。

3D 关键帧来自 `ff-tour-frame.html` / `src/ff-tour-frame.js`。电影用同一套场景和人物，额外把飞空艇摆到街口上方朝向来镜头，并延伸地形避免航拍出现有限地板边缘。电影实例的摆位不改变已发布的游戏场景。

## 衔接

首段同时使用首尾帧和中间帧。第2、3段及第5、6段使用上一段原始 sampler AV latent 的22帧尾部运动上下文，重复头部由原生 Trim 节点移除。第4段从验收过的第3段最后一帧重新开始，不沿用旧音视频 latent。第1、2、4、5、6段均有路线中间关键帧。

原第4段自行加入另一艘偏现代的飞行器，并把机位升到屋顶上方，因此未纳入成片。原第5、6段也随其废弃。重做时新增35、45、55秒的实际3D机位，去掉后半段旋翼声描述，限制街道低位前进；不改共享模型或CLI。原输出、工作流和回执保留供复盘。

按 H3 帧网格，预期243+238+238+243+238+238=1438帧，约59.92秒。实际片长以媒体解码检查为准。生成图像仍可能有局部纹理变化，不能视为几何逐帧严格还原。

## 留档

- `raw-frames/`：无 UI 原始3D关键帧。
- `keyframes/`：通过视觉检查的润色帧，以及开场误借风格图内容的失败样本。
- `cameras.json`：实际位置、视线、拍摄时点。
- `prompts/`：逐帧美术提示与逐段运镜提示。
- `capture-workflow.py`：只修改当前任务的临时图，加中间关键帧并保留精确工作流，不修改共享 CLI。
- `polish-series.py` / `video-series.py` / `polish-mid-series.py` / `repair-video-series.py`：任务串行控制与断点续跑；遇到其他队列任务就停止本轮提交，保留其他任务。
- `receipts/`：本次工作流、回执与时长。

开场第一次润色借用了获认可 B 图的内容而非仅风格，误生成售票亭。已留档，改用实际航拍单图重新润色并检查通过。其余帧保留既定街道/城堡结构。

原始 AV latent 保留在4090的实验专属 output/context 目录，用于续镜，不放进 Git；本地视频与参数可独立查看。

## 参数与复跑

Qwen润色：25步、denoise=1、ref-res=0；共享CLI默认的cfg=1与euler/simple保持不变。各机位seed=14027+时点，修正开场为14127。引用图的内容与风格职责在提示词中明确区分。

H3：`minimax_h3_fl2va_pruned_fp8_scaled.safetensors`，仅加载`minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16.safetensors`，权重1；8步、res_multistep/simple。首三段seed=14027/14028/14029，后半段修正版=15030/15031/15032。精确图在`receipts/*.workflow.json`，文本在`prompts/`。

在已有4090环境中用`polish-series.py`与`polish-mid-series.py`生成关键帧，将验收后的图复制到该实验input根目录；先运行`video-series.py 1 3`，再用第3段解码末帧作为`repair-start-30.png`，运行`repair-video-series.py 4 6`。原失败图与原4至6段仅作复盘，不能替代已验收输出。

本地`python3 experiments/ff9-longtour-20261007/assemble.py`组合验收分段并核对实际解码帧数；`npm run dev`后访问`/experiments/ff9-longtour-20261007/view.html`观看。视频未加入网站的默认构建与部署入口。

## 成片与验收

`FF9-LongTour-B.mp4`：59.9167秒、1438帧、24fps、864×480、H.264、静音。逐段和全片抽帧检查路线，解码帧数与容器帧数一致；浏览器播放及30/40/50秒章节跳转无媒体错误。`media-verification.json`、`browser-checks.json`、`full-film-review.png`和`player-proof.png`保留证据。局部建筑窗户与手绘纹理有轻微漂移。
