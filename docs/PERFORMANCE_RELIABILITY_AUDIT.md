# 王城性能与可靠性审阅

审阅起点为本地 `8cf0e326308684e2d945da1d26fab4005e41db5b`。本轮保留三委托、王城、存档与已通过的美术；不改模型、贴图文件、画质档位或依赖。以下区分代码结论、测试证据和真实浏览器证据。

## 首屏纹理：本轮优先修复

旧 `src/hero.js` 的五张PNG在for循环内逐张await，`src/main.js` 又在场景构建前等待整个函数。任一PNG拒绝都会落入页面最外层catch。五张原始文件共16,394,506字节；并行调度不会减少这些字节，但移除客户端主动施加的请求串行依赖。

新 `src/hero-textures.js` 使用原有成功缓存/失败可重试的加载器，五请求一起启动。失败项生成16×16、与原材质相近的纯色CanvasTexture，保留map/bumpMap接口，广场和远景可继续克隆它们；成功项不替换、不降级。页面明确提示简化材质，并提供独立“重试纹理”，不重载已成功资产或改玩家位置。没有自动轮询或额外网络依赖。

重试保留原Material、Texture、Source对象，把恢复的图像交给已有Source；Three.js 0.170.0的Texture.clone共享Source。重试后扫描已有场景材质，刷新使用同一Source的map/bumpMap上传版本，保留各克隆的repeat与颜色。新加载但未挂入场景的Texture对象随恢复释放，不重建场景。6ed8a33阶段尚无超时；后续按[有限加载约定](ASSET_LOADING_REQUIREMENTS.md)加入网络/解码预算和主动简化入口，避免PNG与角色资源无限等待。布局JSON读取不属于此切片。

定向测试证明：五请求在任一个settle前已启动；并发调用共享一次批次；单项同步失败/全部异步失败保留可用材质；重复失败不重复建fallback；成功项不再请求；恢复后原材质和克隆Source保持，图像与上传版本更新；实际小CanvasTexture兼容广场/远景初始化。测试用可控加载器和轻量DOM，未测浏览器实际传输时间、GPU上传或故障注入后的视觉。不要把请求顺序测试换算成实测首屏提速百分比。

## 其他性能判断

1. 静态合批：`src/batch.js`按材质/阴影属性合并，动态祖先、透明、多材质和反射对象独立。全局材质桶转非索引几何，会扩大内存和包围盒，可能减弱视锥剔除；分区合批也会增加绘制调用。尚无当前视角GPU瓶颈或分区对照数据，本轮不盲目分区或重写几何。
2. 角色/体积：现有三个运行GLB原始合计28,847,336字节，与五张PNG合计45,241,842字节；这不是网络压缩后的传输量。SkinnedMesh材质、骨骼与动作合并会有画质风险，本轮不动角色资产。现有角色并发、简化替身和失败重试保留。
3. UI：`main.js`每0.12秒更新HUD，而非每渲染帧。手记文本已比较新旧字符串；打开标志/Tab属性与一批hidden/disabled仍会重复赋值，诊断JSON也会刷新。代码估算仅Tab与入口有5次setAttribute/次；没有主线程/MutationObserver实测，不能认定它是GPU帧率瓶颈。本轮不以未知收益大改UI更新。

## 资源持有与跨场景

街区链接采用整页导航，不是在单页中持续追加Town。贴图/材质模块缓存属于当前页面；角色成功模板缓存共享几何与材质。晚到角色移除替身并释放其独有几何，保留共享材质。纪念物仅切换可见性，已有24部件合为4个纪念材质网格。新纹理重试在失败集合清空后停止请求，未新增每帧分配或持续定时器。没有内存探针，不声称消除所有资源泄漏。
