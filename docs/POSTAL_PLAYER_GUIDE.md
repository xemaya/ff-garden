# 听风王城：一日邮差

你临时替广场的邮差走一天，把一封问候送出去，再带回大家一起记起的小曲。没有倒计时，也不需要集齐见闻。

## 第一次玩

打开顶部“听风王城”，从敞开的城门进城。沿青瓦主街走到喷泉，广场的邮差、魔导士和陆行鸟会陪你完成三段委托。底栏“手记”里的“委托”页说明当前寄信人、收件人和下一步。

“在地图上找目标”显示“信／收”标记，返回街道保留原位置。走近已加载的人物后，卡片里的交接按钮才可用。顶部“看莫古利／看魔导士／看陆行鸟”也可到人物附近；交接仍要自己点击。邮差正在走近或整理邮包时，停下来等一会儿。

第二段的节拍写在手记里，声音关闭也能回答。记错了可以重读，不会丢信。每封信送达后，再点击“接下一段委托”；第三封回到邮差身边，收到写给你的回信和一页纪念手记。

## 走动与看地图

| 操作 | 桌面 | 触屏界面 |
| --- | --- | --- |
| 行走 | WASD 或方向键；Shift 加速 | 按住屏幕方向按钮 |
| 环顾 | 按住画面拖动 | 拖动画面，可与移动按钮分别操作 |
| 看人物 | 点击人物或顶部角色按钮 | 轻点人物或顶部角色按钮 |
| 地图 | “游览地图”或 M；再次切换返回 | 点“游览地图”，再点“回到街道” |
| 回入口 | Home | 完成一圈后可用“回到街角” |
| 暂停 | 再点游览按钮，或按 Esc；WASD 可接管 | 再点游览按钮，或按方向按钮接管 |

地图的四个路线按钮会沿实际通路自动行走到停靠点；任务的“在地图上找目标”只查看位置。王城路线经过城门、主街、喷泉广场和王宫外庭。宫门关闭，外庭可游览；店铺室内也未开放。

显示选择提供“画质优先”和“流畅优先”。觉得画面吃力时可选后者。环境声默认关闭，用底栏按钮开关。系统要求减少动态效果时，动作可以保持静止，文字仍足以完成委托。

## 可以留在手记里的小事

城门内侧的小石牌、喷泉旁的旧曲小谱、外庭的来客石牌各留了一段城市故事。走近并转向石牌，点击“停下来看看”，故事会出现在“见闻”页；读过后还可重读。

主线不要求任何见闻。送完信后，可以沿着城门出去，也可以继续在外庭歇一会儿。住宅、集市、工坊和入口样板仍可通过顶部导航访问，已保存的邮路随街区切换保留。

## 保存与恢复

进度保存在当前浏览器、当前网站地址的本地存储里，没有账号或云端同步。换浏览器、设备、域名或端口不共享进度。刷新保留已保存的章节和见闻；人物位置与相机不会作为旅程存档保存。

打开手记下方“保存与恢复”：

- “重新开始整段邮路”先让你确认。成功重置前保存当前旅程备份；Home 只回到入口，不会重置委托。
- 有旧版记录时，“恢复旧版第一封信”回到第一章的旧阶段。当前旅程先备份，旧原始记录始终保留。
- “恢复上次旅程备份”可撤销最近一次重置或恢复，包括原来的见闻。确认文字会说明章节、阶段和见闻数。
- 取消、Esc、关闭手记、切换地图或样板都取消待确认操作。刷新不会自动确认它。

备份或写入失败时，页面会说明没有替换当前旅程。普通交信遇到存储失败仍可继续本次游玩，但刷新后可能不能恢复；页面会显示提示。不可识别或更高版本的存档保留原数据，本次只能临时游玩或临时重新开始。

多个标签页共用一份进度。页面会同步其他页更新；在旧目标上操作时可能被取消，并提示按新的目标继续。它没有多人协作或跨设备合并功能。

## 当前体验边界

这是小型静态体验：三封固定剧情信、三个可选故事地点、一个室外王城与已有街区。没有实时AI对话、角色语音、店铺室内或开放的宫殿内部。模型暂时加载失败时，可用“重试角色”；地图仍能参考位置，交接等待角色加载成功。

本机Chrome已对指定开发切片做独立穿行和界面QA；真实iPad Safari、触摸与GPU性能尚未验收。视口模拟和纯逻辑测试不能代替真实设备体验。开发进度与验收范围见[设计记录](postal-journey-design.md)。
