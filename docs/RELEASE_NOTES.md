## 相对基线实际新增

- **可走入的听风王城**：默认入口从旧街道转为王城，连通敞开城门、六店主街、喷泉广场及王宫外庭，约104米导览通路、实体边界和四个地图步行停点。六店有实际名称牌，钟匠/茶屋窗里对应木钟/茶具；议事厅门廊可走近，店铺和宫殿室内仍关闭。
- **三封连贯邮路**：从基线单封莫古利→魔导士，扩为问候信、两短一长的节拍纸条、羽毛印回信。人物必须已加载、走近且空闲才能主动交接；节拍有文字回应与选择，声音默认关也可完成。结尾留下小花、羽毛印和风铃纪念，王城桌有常驻“回信小铃桌”牌。
- **可选故事**：三处物理石牌记录王城见闻，独立于主线；三位居民按章节回应。读城门留言后可给邮差留三选一问候，仅本次页面保留，不写新存档或增加收集门槛。
- **更清楚的操作**：手记增加委托/见闻页、恢复说明与键盘帮助；首次城门提示去喷泉。底栏复用地点小字给当前人物方位和直线距离，近处改成交接说明，地图/手记/展示互斥，主线完成后不留方向任务。阅读时停步，失焦/隐藏/缩放暂停散步；地图快速开关保存实际街道回位。
- **保存与加载可靠性**：新版章节/见闻存档保留旧记录，重置/恢复先备份、确认可取消，最多三条旅程备份，可撤销最近替换；跨标签变化会取消过时操作。PNG并发、失败简化和只重试失败项；PNG/GLB有限下载/解码、取消和迟到结果隔离。必需目录/布局JSON每份5分钟至完整JSON，有停止与失败恢复；主入口及三角色展示可原URL重载/返王城入口。

基线已有的三旧街道、三GLB及动作展示、WASD/触控/自动散步、午后光照和画质选择不是本轮新功能。本轮没有新增下载资产、账号、云存档、后端、模型服务、战斗、交易或室内系统。
