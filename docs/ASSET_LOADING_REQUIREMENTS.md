# 挂起资源的有限处理约定

起点：`6ed8a33`。纹理仍等待加载Promise终止，GLB虽然不阻塞街景，但永久pending会令对应人物永远没有重试入口。Three.js 0.170.0的TextureLoader/GLTFLoader.loadAsync不提供当前调用的可靠AbortSignal；只加Promise.race会遗留网络/解码及晚到模板写入。

本切片只覆盖五张表面PNG和三个现有GLB，不扩展成通用资源框架，不改变素材或角色行为。当前三个GLB的buffer和图片均内嵌，没有外部URI或必需解码扩展。

1. 下载采用可取消的fetch，默认网络等待上限5分钟；数据完整收到后另给2分钟解码窗口，不能因为网络阶段刚好用完预算就立刻丢弃已下载的数据。超时值由加载器参数配置，定向测试使用假时钟。
2. 成功缓存、同一在途调用共享、失败可重试保持。下载超时/主动取消时AbortController终止该下载，解除UI等待；晚到旧成功/失败不得写模板、材质或清掉新请求。旧结果若产生资源，释放其独占几何、材质、纹理及可关闭的图像。
3. GLTF解析和浏览器图片解码不能安全强制中断。超时/取消解除UI等待，最多保留一个该资产的未完成解码；显式重试订阅同一解码并重新给解码预算，不能每次点击再开一个解码。无人等待时晚到结果释放；有当前显式重试等待时才可接收结果。
4. 初始纹理等待提供“先用简化材质进入”选择，终止尚未完成的等待，不取消已成功纹理；进入后沿用单项重试。角色仍以原有替身与失败提示继续，不更改互动的加载门槛。
5. 接收成功资产和写入角色模板必须发生在当前有效请求的提交点；动作验证失败同样释放未接受资产。取消只影响共享当前等待，已成功缓存不清除；不自动重试或轮询。

28项定向资产测试用假时钟/可控Promise覆盖挂起、完整数据后的慢解码、晚到结果、新旧请求隔离、全部/部分超时、手动简化、共享解码、资源与计时器清理、验证失败和并发去重。没有真实等待几分钟。

## 实现与实际边界

`src/asset-loading.js`负责缓存、当前等待与独占下载/解码的提交点；默认无超时保持原通用调用兼容，PNG/角色工厂显式采用上述5分钟+2分钟预算。`src/asset-transport.js`将字节获取改为fetch，PNG仍用TextureLoader解本地blob URL，保持原翻转/颜色行为；GLB完整下载后用parseAsync，原动作验证和模板赋值移到有效请求accept步骤。角色行为、动画和展示接口未改变。

PNG对象URL在解码成功或失败后释放；GLB的独立LoadingManager跟踪本解析生成的blob URL，解析成功或失败后补充释放，重复revoke安全。晚到完整GLB按Set去重释放几何、骨架、材质、贴图及可关闭图像；动作验证失败同样释放。原生解码永不终止时，每个资源至多保留一个未完成解码及其尚在使用的blob，不声称强制释放一个仍在被浏览器使用的解码。解析中途失败但未返回完整GLB时，其内部临时对象依赖Three.js与浏览器回收；它们未挂入场景/上传GPU，不能把完整结果的dispose测试宣称为所有原生内部工作都可取消。

“先用简化材质进入”只取消当前PNG等待，已成功缓存保留，GLB继续后台加载；它在布局JSON加载完成后才出现。本切片没有给manifest/布局JSON加预算，没有引入AbortSignal.throwIfAborted较新API，也没有测试真实Safari或慢网。后续应针对正常PNG/GLB显示、入口按钮与异常降级做有限浏览器检查。

## 所有权复审

| 对象 | 所有者与释放边界 |
| --- | --- |
| 当前等待Promise、deadline | loader；一次结果/失败/取消即清timer；并发调用返回同一Promise |
| 下载/解码工作 | 一个operation；下载取消就abort，原生解码可留下且只供显式重试复用 |
| 成功GLB | 成功缓存/角色模板；实例共享几何和材质，不能在实例创建后按“未使用”dispose |
| 成功PNG | 材质/共享Source；降级恢复只释放新Texture容器，图像转交原Source供克隆继续使用 |
| 未接收的完整结果 | loader的dispose回调；不写模板，不触碰已经接收的共享资产 |

复审保留这两层状态，是因为“界面已不等”和“原生解码仍在做”确实不同。没有任务队列、优先级、自动重试或全局框架。旧单参数load调用、成功Promise缓存和失败重试行为由原有7项测试保留；新cancel方法只补取消共享等待，不替代这些接口。

0d0fbd5独立Chrome QA通过主场景五PNG/三GLB和三展示页动作，四页warning/error为空。简化入口加载太快未观察到，故障/取消/晚到仍只有自动测试证据，不宣称浏览器故障通过。

后续启动补缺口：目录/布局JSON现已复用有限加载器，每份从fetch到完整JSON共享5分钟预算，并加停止等待/失败恢复；三展示的有限模型等待也获得停止与重载入口。详见[启动恢复](STARTUP_RECOVERY.md)。这不改变0d0fbd5时28项资产测试和普通资源QA的历史范围；新增6项启动测试尚未浏览器故障验证。
