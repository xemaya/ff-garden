# 三人 v1 否决与 Steiner 重做

2026-10-08，用户否决 Steiner、Zidane、Garnet v1：不像且丑。三人已从城市加载、摆位和碰撞代理中撤下。保留旧 GLB、Blend、生成配方和工作室，作为失败对照。33 位原居民及城市建筑继续使用。

## 失败原因

三人共用近似身体和头型，靠服装颜色、面部照片投射补身份。正面似乎有特征，环顾后仍是通用人偶。动物样本的成功没有证明同样的程序化方法能还原人类主角。

Steiner 的生成目标图也偏离原作：把尖顶宽檐头盔画成了带槽面罩，把短裤和裸露肘部改成全甲。原先虽引用官方页面，却没有充分核对官方立体造型。继续追着错误目标加细节，会越做越错。

骨骼、动画、文件结构、碰撞回归通过，只能证明可运行，不能作为“精修完成”或角色像不像的证据。

## 本轮调整

采用 [Square Enix 官方 Bring Arts Steiner 立体造型](https://na.finalfantasy.com/news/1130) 作为识别轮廓依据。专属身体比例、方下颌、内嵌眼窝、倾斜上眼睑、压低的眉毛和嘴线；不使用旧脸部图集。服装改为尖顶宽檐头盔、连接帽体的细长银羽、单片下垂肩甲、锁子甲短袖、裸露肘部、宽护手、叠片护裙、卷边短裤、裸露脚踝和尖头护足，背剑通过宽斜肩带固定。

源码 `tools/build-steiner-v2.py` 复用旧文件的基础网格工具函数，人物形体与配件重新定义，不改动三人 v1 或已验收动物。可编辑源和 GLB 分别为 `authoring/characters/royal-cast/steiner-v2.blend`、`public/assets/characters/royal-cast/steiner-v2.glb`。21 关节、四段动作，当前衣服和护甲分件刚性绑定；不是完整布料模拟或生产级人物蒙皮。

在 `/steiner.html` 检查正面、侧面、背面、脸部与四动作；`/royal-cast.html` 明确标为旧版未通过。新样本尚未放回城市。Zidane、Garnet 尚未重做。

本轮没有新生图、远程4090推理或训练。两张布料颜色纹理由本地脚本生成，脸部全为几何结构。

## 当前验收边界

- 已完成整套 `npm run check`，城市六分钟模拟维持33位居民，十人队伍同步、移动碰撞、起跳、暂停和减少动态设置通过。
- 最终资产执行 `npm run verify:steiner`：四段真实骨骼动画、归一化权重、循环接缝及解码蒙皮的地面检查。没有声称所有护甲/关节姿态均不穿模。
- 浏览器正侧背、面部和动作截图、运行状态在 `evidence/steiner-v2/`；手机布局使用375×667的iframe检查。
- `npm run build` 包含新的单角色工作台。

造型仍待人工验收。目前是可环顾的专属造型样本，材质老化、衣褶及关节连接还有精度差距。先以一个人物的实际渲染确认方向，再继续另外两人，不能把待审样本默认摆回王城。

## v3：羽毛、头身比例与护甲包覆

用户反馈 v2 明显改善，但羽毛像长刺、脸大身小、护甲没有包住四肢。本轮保留 v2 GLB、Blend 和截图，工作台改为加载 v3。

- 全部头脸、眼睛、头发和头盔共用同一缩放支点：横向及高度缩小13%，深度缩小10%。躯干与四肢横向加厚9%；髋部以上的身体高度增加8%，腿长保持原样。头部骨骼位置同步改变。
- 羽毛从直线细片改为较短的弯曲羽轴、非对称宽羽片、逐渐扭转的羽面与26条细羽纹；侧面也有可见羽面。羽毛颜色改为无金属反射的银白色。
- 肩甲延伸到锁子甲袖子的前后，前臂护甲加长、收窄口径；腿甲移到大腿中心并包住前方与两侧。上层腿甲挂在腰部，下两层跟随各自大腿，后侧有固定带。
- 护足补上环抱脚跟与下脚踝的甲片，肘部和卷边短裤下方保留短的关节活动间隙。

源码为 `tools/build-steiner-v3.py`，产物为 `steiner-v3.glb` 与 `steiner-v3.blend`，实际渲染与验证保存在 `evidence/steiner-v3/`。工作台仍使用 `/steiner.html`。v3 尚待人工造型验收，不自动放回城市；也不代表任意动作下的全身接触都已验证。

本轮验证：`npm run verify:steiner` 与 `npm run build` 通过；浏览器检查四方向、四动作、走路25%和75%两次迈步峰值及375×667布局。肩甲内衬收进外壳，滚边的截面方向保持连续；旧v2 GLB哈希与保存记录一致。

## v4：继续收脸，并重塑面部

用户仍认为 v3 脸太大、与素材图差距远。本轮保留 v3，工作台加载 v4；新增「看头部素材图」以便直接对照既有参考。

在重新塑形之外，脸部整体变换相对 v3 横向收小约24%、高度约25%。头盔另外收小并降低位置，避免缩脸后出现过大的头盔空腔。头部骨骼与五官同步调整，身体与盔甲几何继续使用 v3 的方案。

面部从直筒脸改为收窄的下颌与较清楚的面颊过渡。颧骨和嘴唇写入连续面部曲面，不叠加独立球块；眼窝沿脸部曲面嵌入，眼球按照面部局部方向倾斜，缩小眼白、虹膜及瞳孔，压低上眼睑，收细并贴合眉毛，加入轻微眉间纹。肤色与表面粗糙度也向素材图的成人脸调整。继续使用三维五官，不恢复脸部照片投射。

源码、可编辑源和运行资产分别是 `tools/build-steiner-v4.py`、`authoring/characters/royal-cast/steiner-v4.blend`、`public/assets/characters/royal-cast/steiner-v4.glb`。实际渲染和验证保存在 `evidence/steiner-v4/`。没有新增生图、远程推理或训练；仍需要用户判断脸型和相似度，机器通过只证明可运行。

v4验证：`npm run verify:steiner` 与 `npm run build` 通过；四方向、四动作、素材对照弹窗和375×667布局在浏览器检查。构建GLB与源文件一致，旧v3 GLB哈希未改变。
