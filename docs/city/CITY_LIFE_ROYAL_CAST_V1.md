# 城市街坊与三位王城角色

日期：2026-10-08。城市入口 `/city.html`，工作室 `/royal-cast.html`，合影 `/royal-cast.html?character=all`。

## 城市中的活动

在原49栋城市布景中共有36位角色：十人魔导士巡逻队、18位路人、两只莫古力、一只陆行鸟、两位原有魔导士和Steiner、Zidane、Garnet。

- 巡逻复用已验收的魔导士v2 GLB，十个独立骨骼实例，按两列错位队形、统一进度走主街与集市环路。转角收窄队形，接近访客时保持通行间距。首尾接头也平滑，避免一圈结束后角度突变导致队伍停死。
- 莫古力继续复用v3，路线移动叠加约16厘米的根节点起落、落地轻微挤压与已有骨骼动作。这是程序化小跳，不是新导出的Hop骨骼片段或真实弹跳动力学。
- 陆行鸟复用v1，播放Walk并沿广场绕行，遇到桌椅、人物或路口拥挤时停让或局部重规划。
- 路人有六种服装配色、帽子、围裙与背包组合，共18人，使用轻量Three.js几何与关节层级步态。它们不是新增18份GLB，形态没有按原作特定人物精修。
- 路人主要在住宅、庭院和上城区循环，给巡逻保留主街/集市通行带。局部避让使用障碍数据和网格连接，移动碰撞圆每帧同步；这不是语言模型自主行为或任意拥挤条件的通用导航。
-「街坊活动」暂停/恢复所有居民和三位主角；减少动态效果设置下默认停止，用户可主动开启。原街道页面、三份已验收角色GLB与建筑材质保持原样。

`src/city-life.js` 为路线、队形、起落和避让；`src/townsfolk.js` 为路人外观和步态；`src/royal-plan.js` 为三位主角的摆位与碰撞边界。城市布局计数仍指环境装配，新增角色美术的生成次数单独记录。

## Steiner、Zidane、Garnet

三人各有真实GLB、可编辑Blend源文件、共同的21骨骼结构与四段动作：Idle、Walk、Greet、Signature。待机/走路循环，招呼/角色动作单次播放。工作室可分别看正面、侧面、背面，环顾、缩放、切动作、定格、查看动作进度，以及三人合影。

网格、闭合躯干与肩臂、骨架、热权重、衣服和配件、动作由 `tools/build-royal-cast.py` 制作。刚性护甲、头发和配件绑到对应骨骼，最终合并为单一蒙皮对象中的材质分组，每人10–11个材质绘制。每顶点最多四个影响，纹理嵌入GLB。

第一轮原型的脸相似、头发像细绳、肩甲像叠球，已保留在 `evidence/royal-cast/prototype-v0/`。当前版重新区分脸部：Steiner的方下颌与严肃表情、Zidane的蓝眼与轻快神态、Garnet的棕眼与柔和面部；脸部颜色投到实际头部网格，头发仍为有体积的雕塑。Steiner增加抬起的有槽面罩、空心搭接肩甲、铆钉和风化钢材，Zidane保留金发、尾巴、蓝衣与大袖口，Garnet保留长黑发、橙色旅行服、白袖与红褐手套。

独立脸部表情、嘴形和眨眼没有实现；脸部纹理中的表情固定，头部和身体能够动画。衣服、头发和护甲是绑定/烘焙控制，不是布料、毛发或铠甲物理。

## 美术与资源

内置 `image_gen` 共5次成功调用：三张角色造型目标图、一张三人脸部颜色图集、一张钢材颜色图。布料颜色与细织纹由Blender脚本程序化制作。参考图只指导造型；脸和钢材颜色图是运行材质；图像模型没有直接输出三维网格或骨骼。

没有训练新模型，没有调用4090上的生成服务。服装核对使用 [官方Zidane/Garnet立体造型](https://na.finalfantasy.com/news/1057)，角色参考包括 [官方角色页面](https://na.finalfantasy.com/titles/finalfantasy9) 与 [Steiner参考](https://na.finalfantasy.com/news/1130)。配方、提示词、尺寸与哈希保存在 `art-direction/royal-cast/`。

## 验收与边界

- `npm run verify:city-life`：六分钟模拟、移动圆同步、障碍/个人间距、十人共同进度、两圈连续巡逻、路人/鸟持续前进、跳跃高度、暂停与减少动态效果。首次拥挤路线和未平滑的循环接头出现停死，现按通行带与循环接头修正。
- `npm run verify:royal`：GLB结构、21关节、归一化四权重、嵌入图片、加权骨骼确实变化、待机/走路接缝、每段九个解码蒙皮姿态的地面检查。
- 浏览器确认十人都播放Walk且队伍持续移动，三位主角、跳动莫古力和游走陆行鸟出现在实际城市；工作室检查三人各四动作与三个方向。截图和运行快照在 `evidence/city-life/`、`evidence/royal-cast/`。

水平圆形代理不是逐三角形或逐骨骼接触，台阶只跟随地面高度，没有足底IK。暂停会定格当前起跳姿态。少量路人可以停留等待，任意长时间、任意密度与任意访客轨迹未获得证明。机器通过和实际渲染不等于人的造型验收，三位新角色仍待用户评价。

## 动态游览回归

动态障碍会让一次移动请求只前进一部分。游览现在按实际位移累计距离，保留尚未抵达的路点，剩余量低于1e-5即结束本帧，并限制循环次数。原先浮点微小余量可能令浏览器持续循环，测试页失去响应；`src/city-tour.js`及`tools/city-tour.test.mjs`覆盖余量、零位移、部分移动和完成距离。修复版实际动态游览完成约390.14米，记录在`evidence/city-life/browser-tour.json`。

375×667布局检查使用同源iframe的真实375px视口，城市菜单与底栏分开、横向不溢出，工作室完整显示合影。截图保存于两份evidence目录；这是浏览器响应式布局证明，不是实体手机触控或性能验收。
