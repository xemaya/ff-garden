# 王城小城：从一条街到街区网络

日期：2026-10-07。入口：`/city.html`。目标是用已有资产构成有纵深、支巷、回环与高低层次的可游览小城，为下一次视频提供更完整的实际布景。

## 空间与资产

- 街区主体49栋：原工坊街8栋位置、尺寸和组件配方保留，新增41栋规则装配住宅与店铺。既有王城远景里的建筑不计入49栋。
- 五个区域：入口街坊、工坊主街、集市巷、住宅巷、上城区。两个庭院分别连向主街/集市和入口/住宅巷。
- 37条图边是道路分段，不代表37条独立街道。道路图全部连通，有11个独立环；自动游览沿约390.14米的闭合路线经过两侧支巷、广场和上城。
- 城区可游范围约63×114米。上城区为0、1.45、2.9米三层，连接楼梯每级高约0.181米。导航高度与可见台阶共用高度函数。
- 补侧面与背面门窗、曲面屋顶、屋顶木边、连续住宅、后院花槽、城门、城墙、钟楼和台阶栏杆。原主街原先隐藏的背墙在城市实例中补细节。
- 保留喷泉、戏亭、飞空剧场和已验收的莫古利/魔导士/陆行鸟；在支巷增加两位邻居，庭院和街边加入已有花盆、花车、邮筒、长椅。
- 王城继续作为远景建筑，不提供室内或王宫内部游览。新增实际台地与基座，补上原远景建筑底部与城市地形之间的连接。

## 生成边界

这次是人工确定的城区道路模板加程序化组件装配。既有8栋主街读取先前4B输出；新城区没有调用4B，也没有训练模型、生成图片或新增GLB。不能把本次结果称为小模型独立生成了城市。

`src/city-plan.js` 负责道路节点、街坊、模块选择、碰撞、庭院、观景点及回环。`compileCity(raw,{seed})` 使用固定合法目录生成确定性配方。种子会改变材质/楼层等组合，城区拓扑仍是同一模板；任意文字需求和新拓扑尚未验证。

`src/city-assets.js` 复用原来的五张PNG材质与现有几何组件，近处完整立面，远处保留轮廓、木梁与简化窗。新增41栋按空间分为8个块，各块独立合批，并在130米处切换简化模型，使用10%回滞。角色和水面保持动态对象。

`src/city-main.js` 提供航拍、七个地面观景点、地图、WASD/方向键、拖拽转向、触控方向按钮、慢逛/快览和回入口。城市入口已纳入Vite生产构建，原街道入口增加链接。

## 验收证据

- `npm run verify:city`：49栋建筑无相互重叠，所有道路、庭院节点连通，全部道路与回环按0.05米采样检查约18,856个位置；全部地面观景点可占据，台阶高差可通过，边界阻止越界。
- `npm run verify:v4`：原三街道配方、落位与五张材质SHA-256保持一致。
- `npm run test:input`：已有多输入所有权与取消行为测试通过。
- `npm run build`：城市及原入口构建通过。仍有原有Three.js共享包大于500KB的提示。
- 真实浏览器快览走完约390.14米，回到入口，`completedTours=1`、`blockedSteps=0`；见 `evidence/city-v1/browser-loop.json`。这是自动游览证明，不能替代人的好逛程度验收。
- 各区域、地图、航拍和375×812布局截图及运行快照保存在 `evidence/city-v1/`。浏览器性能快照仅代表当次宿主与视角；渲染调用和三角形计数包含阴影及多个后处理pass，不是单次主画面的计数。

## 已知范围与继续精修

第一版验证的是城市空间、组件复用和通行。外围城区仍采用规则模板；窗户、门和部分种植较重复。支巷里的人物没有新的任务，建筑室内没有开放，角色行为没有扩展到城区居民AI。王城本体仍需后续美术精修。

下一轮应根据人的实际游览反馈调整街坊轮廓、转角与遮挡节奏，先精修少量街区模块，再复用到多个城区模板。城市布景未重新生成一分钟视频；新的路线与机位可以用于后续视频制作。
