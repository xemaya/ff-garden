# Garnet v2 独立角色修订

v1 的三人通用身体与脸部照片投射已被用户否决。本轮按已有 `art-direction/royal-cast/garnet-target-v1.png` 重做 Garnet：窄肩、腰线、连贯的腰胯与腿、白色垂坠袖、橙色旅行服、白手套、棕色低跟靴、绿吊坠和低束长发。采用素材图中的白手套，不把参考图各处服装细节都声称为原作唯一版本。

身体核心是肩臂、躯干和双腿连成的网格；袖子与衣身按解剖区域使用平滑的骨骼混合权重。顶点最多四个影响并归一化，护带、吊坠和手套等仍以对应骨骼固定。动作是待机、走路、招呼和点头致意，没有布料模拟或手指独立骨架。

脸部复用连续面部曲面及五官贴合的数学工具，另设 Garnet 的脸型、下半脸长度、柔和的眉眼、微笑、较短的鼻子和少女面部比例。不使用旧脸部图集。黑发以闭合发冠、成片中分发束、细发纹及低马尾形成整体，避免头顶开口与头皮穿出。衣服是有曲面和厚度的实际网格，不是角色图片的平面展示。

参考图只指导造型；运行资产由本地 Blender 脚本生成，未新增生图、远程4090推理或训练。橙色与白色布料颜色/细织纹由程序生成。没有将新角色默认放入城市，先在独立工作台检查。

- 工作台：`/garnet.html`，正面、侧面、背面、脸部、四动作、定格和素材对照。
- 运行模型：`public/assets/characters/royal-cast/garnet-v2.glb`。
- 可编辑源：`authoring/characters/royal-cast/garnet-v2.blend`。
- 生成器：`tools/build-garnet-v2.py`，依赖既有网格工具和面部曲面工具，身体与造型另行定义。
- 检查记录：`evidence/garnet-v2/`，包括实际浏览器渲染及解码蒙皮检查。

v1 GLB保留为失败对照，Steiner v4 保留。机器验证只证明可运行和规定采样范围，造型与相似度仍待用户验收。

验证结果：`npm run verify:garnet`、`npm run verify:steiner` 和 `npm run build` 通过。浏览器保存四方向、四动作与走路25%/75%两个迈步峰值，素材对照弹窗可打开；375×667双iframe确认 Garnet v2 与 Steiner v4 各自加载，页面没有横向溢出。构建GLB与源GLB一致，旧Garnet v1及Steiner v4文件哈希保持一致。记录不代表所有任意姿态的衣服接触都已证明。
