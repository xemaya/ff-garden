# 听风王城：首次体验脚本

目标是让第一次来的人在3–5分钟内完成一段有开头、回应和回信的小旅程，再自行决定是否留下散步。时间是内容节奏估计，未做用户计时测量；读速、加载和走法会影响时长。无需读工程说明、开声音或集齐石牌。

## 主体验

| 参考节奏 | 玩家所见与所做 | 反馈与下一步 |
| --- | --- | --- |
| 0:00–0:40 | 站在城门外，标题下直接写“到喷泉广场，找莫古利接信”。城门迎客卡说明沿青瓦主街走，或用顶部“看莫古利”；底栏手记可读邀请。 | 城门是入口，去住宅巷是可选出口。初次不会被直接赶向旧街，也没有强制弹窗。 |
| 0:40–1:40 | 穿过主街，看见回声旅舍、青瓦邮局、钟匠小屋、晨光面包房、纸页书坊、旅人茶屋的门牌。到喷泉，走近花车旁邮差，在手记收下问候。 | 小花信封送给魔导士；地图“信/收”标人物、圆点标玩家。交接要走近主动点，地图定位不会传送或完成。 |
| 1:40–2:40 | 把信交给书桌旁魔导士，读它收到问候的反应，再接节拍纸条，交给树荫边陆行鸟。 | 第二章不是新一轮同样问候：魔导士记不起旧曲，陆行鸟把两短一长写进回应。文字有明确答案，错了可再读，不丢信。 |
| 2:40–3:40 | 选“两短一长”，读羽毛印回信，再主动接最后一段，走回邮差交信。 | 莫古利把谢谢写给玩家。已开声音才有一次回响，关声音同样完成。手记结尾指向喷泉朝入口一侧的小铃桌。 |
| 3:40–5:00 | 关闭手记，看看小花、羽毛印和三根风铃，听街坊收工后的话。 | 没有下一项领奖或必须清掉的格子。可收起这一页离开，也可去外庭继续逛。 |

“慢慢逛一圈”沿完整通路到外庭，并不替玩家送信；地图四个路线按钮也只是步行停靠。想做主线时，到喷泉停下即可。短句指引与手记目标承担导航，门牌只让街道中的地点可辨认，店铺和宫殿室内没有开放。

## 可选散步

城门内左侧石牌讲“请进，也等你回来”；喷泉旁的小谱讲给走得慢的人留一拍；外庭右侧石牌讲不必递交姓名的歇脚位置。三段故事共同解释旧曲，两短一长不是收集奖励。任何一块都可以单独读，主线不依赖它们。

可从城门先读一块，沿主街做完三封信，再读喷泉小谱、走到王宫外庭；也可先逛外庭再回广场做邮差。外庭门匾、地图和停靠点统一叫“王宫外庭”。已读故事留在见闻页，重复阅读不累计。

六家店与故事的关系：旅舍留灯，邮局整理问候，钟匠保存旧钟，面包房迎早行者，书坊抄旧曲，茶屋给等回信的人留一桌。它们提供生活背景，不新增购物或室内交互。三位街坊随邮路阶段回应，可选石牌为各人加一句回忆，不推进任务。

## 本段实际修订

- 城门初次、继续、收工三种指引随有效旅程显示；收工不再提示接第一封信。
- 短副标题在首次进入就给地点和动作；门牌显示实际店名，保留原建筑轮廓。
- 地图增加一行标记图例；第四个停靠点仍需在目标视口实际核对可见性。
- 把节拍说明写成玩家能读懂的话，删掉许诺未实现演唱的台词。结尾正文从203个字符缩到130个字符，并指向小铃桌。
- 手记打开时石牌/出口卡也隐藏；窄屏石牌样式不再覆盖hidden。此处是代码修复，待浏览器点击与显示检查。
