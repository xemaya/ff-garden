# 支线 · 寄给点灯人的信

玩家身份：王城的见习邮差。JRPG 里帮人送信的支线，这一封在路上牵出一段小剧情、两次打听、一次等待和三段过场动画，最后在城外得到回音。

一句话：面包房的面粉袋里夹着一封没有地址的信，寄给"每天黄昏点亮第一盏灯的人"。邮差找到了这个人——巡逻队里最小的见习黑魔导士维维——又替他把一盏小火苗送回城外风车上的写信人。

## 人物

| 人物 | 在哪 | 作用 |
|---|---|---|
| 面包师 | 集市巷面包房（已有） | 发起委托，交出信 |
| 书桌旁的魔导士 | 喷泉广场（已有 neighbor-2） | 线索一：巡逻队黄昏会在城门停一下 |
| 巡逻队魔导士 | 主街/集市巷巡逻（已有 patrol-*） | 线索二：队伍里最小的那个，黄昏总在城门 |
| 维维 | 新增，黑魔导士模型缩小 0.78 | 点灯人。只会放很小的火苗，所以一盏一盏点灯 |
| 小麦 | 不出场 | 写信的人，住在城西风车磨坊。只通过信和风车的灯出现 |

## 流程

| 步骤 | 玩家做什么 | 世界里发生什么 |
|---|---|---|
| invite | 面包房门口有 `!`，进门对面包师按 E | **过场 A**：镜头推近面包师，信从柜台飞到手里；章节卡"寄给点灯人的信" |
| read | 按 R 或点"手中的信" | 信纸展开（手写信）。线索：灯从城门亮到王宫，一共八盏 |
| ask | 找喷泉边的魔导士、拦住巡逻队各问一次（0/2） | 对方转身面对你；巡逻队整队停下等他说完 |
| wait | 黄昏时到城门石阶，按 E 坐下 | 黄昏时街灯全灭（"灯还没亮"）。**过场 B · 点灯**：白天则先快进到黄昏；维维从城门走进来，举杖放出火苗，火苗一分为二沿街两侧飞，八盏灯依次点亮，镜头追着火苗一路飞到王宫门口；回到城门，维维发现你 |
| meet | 对维维按 E 交信 | **过场 C**：信飞到他手里，他读两遍；道出身世；把火苗放进提灯，提灯飞到你手里 |
| carry | 提着灯走到上城西角的观风柱 | 手里的提灯真的照亮周围的街巷 |
| done | 按 E 挂灯 | **过场 D**：镜头升过屋顶望向城西风车；风车上的灯亮三下——两短一长（呼应一日邮差的风铃节拍）；结束卡 + 纪念 |

完成后：观风柱上挂着提灯；黄昏时风车窗口一直亮着；维维留在城门，可以聊天。

## 设计取舍

- **每一步都是世界里的动作**：E 键靠近交互，头顶有动词提示，目标头顶有 `!`；对白用打字机效果加名牌，过场有上下黑边，可按 Esc 跳过。
- **不新增美术资产**：维维复用黑魔导士 glb；信、提灯、观风柱、火苗都是程序化几何和贴图。
- **不打扰已有系统**：一日邮差、面包房、巡逻队照旧运行；这段支线另存一份进度（`ff-garden.lamplighter.v1`），只能在步骤边界存档，刷新后从当前步骤继续。
- **声音**：全部用 WebAudio 合成（打字声、拿起物品、火苗、点灯音阶、风车回应）。右上角有开关，可以关掉。
- **性能**：只多一个角色和一盏点光源（提灯）。点光源在启动时就加入场景，避免中途加灯引起着色器重编译。

## 实现位置

- `src/story-director.js`：通用的剧情层，包括对白、过场时间轴与镜头、交互提示、任务标记、追踪栏、卡片、信纸、手持物。
- `src/city-sfx.js`：程序化音效。
- `src/lamplighter-story.js`：纯数据和状态机（可单测）。
- `src/episode-lamplighter.js`：世界物件和四段过场。
- `src/city-atmosphere.js`：增加 `setStreetLights`，让街灯可以逐盏控制。
- `tools/lamplighter-story.test.mjs`：状态机与存档测试。
