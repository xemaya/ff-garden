# FF Garden · 风铃街

[跨阶段经验记录](docs/WORLD_GENERATION_LESSONS.md) · [三街道验证报告](EXPERIMENT_V4.md)

一个受 FF9 王城、飞空剧场与奇幻街坊启发的 3D 街区实验。当前开发内容加入原创“听风王城”和“一日邮差”：城门、主街、喷泉广场、王宫外庭构成约104米步行路线，三封关联委托与三块可选故事石牌组成一段完整小旅程。复用已有建筑、材质和角色，保持静态站点架构。

[玩法与操作说明](docs/POSTAL_PLAYER_GUIDE.md) · [开发设计与验收记录](docs/postal-journey-design.md) · [本地听风王城](http://127.0.0.1:5209/?district=royal)。当前六小时迭代仍在开发验收中，未部署到线上；线上内容与本地开发切片可能不同。

本地无参数入口默认进入听风王城，指定住宅、集市、工坊或样板的旧链接保持原目的地。三位街坊随信件阶段回应，读过石牌后可听到对应旧事；完成回信在广场留下小铃桌纪念。声音仍默认关闭，只有主动启用后最终交接才会用已有程序音色回响两短一长。

线上：<https://ff.buplayground.cn/> · [部署与回滚](deploy/README.md) · 仓库：<https://github.com/xemaya/ff-garden>。

本地预览：<http://127.0.0.1:5209/>。原 FF7 实验继续保留在 <http://127.0.0.1:5207/>。

## 第四轮：同一美术库生成三条街

当前入口 <http://127.0.0.1:5209/> 提供住宅巷、集市街、工坊街。入口精修样板保留在 <http://127.0.0.1:5209/?sample=1&study=1>。

本轮真实调用已有 Qwen 4B：分别选择 6/10/8 栋建筑与模块组合。程序做间距求解与碰撞检查，原始位置偏好和实际落位都有记录；没有手工替换模型输出，也没有新增生图，五张材质文件哈希不变。[实验结果、资源、失败记录和验证](EXPERIMENT_V4.md)。

验证：`npm run verify:v4`。复现生成：`npm run generate:streets`（需要已配置的 4090 主机与缓存模型）。浏览器切换读取保存的模型输出，预览不需要推理服务。人的美术一致性判断仍需看真实截图与场景。

## 第三轮：美术目标与两栋建筑精修

[美术目标图](art-direction/ff9-street-target-v1.png)由内置 imagegen 生成；[入口精修样板](http://127.0.0.1:5209/?sample=1&study=1)是可实时渲染的 3D 场景。目标图不会作为街道背景贴入画面。

精修范围为入口的花店、面包店和约 18 米石板路。五张生成的颜色材质实际接入灰泥、木材、路面、红瓦和青瓦；两栋建筑重新搭建了墙面开口、深窗洞、拱框、凸窗、木梁、檐口、铁艺招牌、店内货架与花盆。屋顶包含 600 片有曲面的瓦片，前景路面有 154 块低起伏石板。光照补充屏幕空间环境遮蔽以加强接触处的深度。

点击顶部「◈ 精修样板」可隐藏标题、角色与飞空艇，专门检查建筑和路面；窄窗口显示 ◈ 图标。Esc /「返回街道」退出，WASD 也可恢复行走。地图与样板模式会正确恢复之前的街道位置。

这一轮保留了其他六栋店铺、角色、城市远景的简化造型。实时样板在纹理、建筑深度和瓦片轮廓上推进了一步，仍未达到目标图的全部细节和整体构图，人的美术验收尚未完成。新增图片是颜色材质；凹凸从颜色图近似取得，不是完整的雕刻法线/粗糙度资产包。

图片来源、提示词在 `art-direction/generated-assets.json`、`target-prompt.txt`、`texture-prompts.json`；材质在 `public/assets/v3/`。源码、旧图和旧浏览器结果已版本归档，第二版源码为 `evidence/v2-royal-city-source.zip`。资产尺寸、PNG 格式、SHA-256、碰撞与浏览器验证均写入 `evidence/`。这一轮未启动 4090 上的新推理或训练任务。

## 第二轮美术修订

第一版得到的反馈是“可爱风有了，但 FF 的感觉完全没有了”。这一轮改场景本身，而不仅换色或修改标题：

- 圆塔城堡替换为层叠王城、拱桥、侧面钟楼和高耸的剑形中央塔楼。
- 气球小飞艇替换为木质船体、金属肋骨、剧场立面、尖顶塔楼、机械旋翼组成的飞空剧场。
- 建筑加入不同的凸窗塔、弯曲陡屋顶、阳台、边角旧石材、纹章和错落的轮廓；广场入口新增高架石拱门。
- 新做黑魔法师、莫古利、陆行鸟与鼠族街坊的简化 3D 造型，与普通居民一起分布在街上。
- 保留晴天与闲逛路线。奇幻居民和飞空艇内部做几何合批，旋翼仍独立动画。

造型均由本项目代码搭建，没有导入原游戏模型或贴图。它们是辨识度实验，尚不能等同于 FF9 原版的手绘背景质感；风格是否到位仍需人的判断。

参考： [Square Enix 官方 FF9 画面](https://www.jp.square-enix.com/game/detail/ff9/)、[官方 20 周年美术访谈](https://na.finalfantasy.com/topics/193)及[亚历山德里亚游戏画面](https://fantasyanime.com/finalfantasy/ff9/screenshots/01-Alexandria.html)。访谈将飞空艇停靠城堡的画面、角色的夸张表现、剧场主题和背景的明暗组织作为可参考的线索。

第一版源码在 `evidence/v1-storybook-source.zip`，截图以 `-v1.jpg` 保存；第二版入口画面为 `evidence/street-entry-v2.jpg`。这两个版本共享一条经过验证的行走路线。

## 第一轮基础场景（历史记录）

- 约 64 米的弯曲步行路线，8 间不同的店铺，包括面包店、花屋、旅店、玩具铺、茶馆、书房、小屋与药草屋。
- 新做的圆角灰泥建筑、陡坡瓦屋顶、拱窗与百叶窗、条纹雨棚、立体招牌、花箱、货物和小推车。
- 树荫休息处、长椅、喷泉、水晶、王城、飞空剧场与奇幻街坊人物。
- 自动步行游览、自由行走、拖拽环顾、鸟瞰地图与四个路线停靠点、晴天/午后光照、默认关闭的程序化环境声。
- 平面行走范围与建筑、摆件、人物、喷泉的碰撞边界。

这是可实时环顾和行走的 Three.js 几何场景。建筑、材质、招牌、植物、人物与道具由程序创建；没有使用游戏原版素材。

第一轮专门验证“明亮童话乐园”的美术与空间方向。`public/data/town.json` 是人工编写的固定布局，**没有调用小模型生成这份布局，也没有新增训练或远端 GPU 推理任务**。第四轮的小模型生成链路与数据在 `public/data/v4/`；此处的 `town.json` 继续作为固定入口样板。

## 操作

点击「慢慢逛一圈」沿路线自动游览；王城走到宫殿外庭，原三街走到广场观景点。再次点击暂停。WASD / 方向键自由行走，Shift 加速，拖拽画面环顾，Home 回入口，M 切换地图，Esc 停止游览。地图上的停靠点会沿街道实际步行抵达。

三种角色模型会并发加载，街景无需等待它们全部完成：加载期间先显示已有简化造型，并逐个原位恢复精修角色。页面会提示加载中或失败的角色；点击「重试角色」只重载失败角色，成功后原位恢复精修模型和互动。

## 本地运行

```sh
npm ci
npm run dev
npm run check
npm run build
```

本仓库独立安装依赖，使用 `npm ci` 可按锁文件复现。Vite 缓存与生产构建分别写入 `.vite` 和 `dist`。

## 验证与边界

`tools/verify.mjs` 检查路线全程的扫掠碰撞、建筑与道具碰撞、边界限制和四个停靠点的可达性。结果在 `evidence/navigation-verification.json`；真实浏览器验证与截图在 `evidence/`。

当前仍是小型美术与玩法体验原型：三封预写委托、文字节拍回应和纪念结尾已接入；听风王城可以实际步行到外庭。店铺与宫殿内部未开放，碰撞采用平面圆形/矩形近似，原三街仍保留历史城市远景。真实设备性能与整体美术质量仍需实际体验判断。

### 触控与显示质量

触屏设备可按住方向键移动，拖动画面环顾，轻点已加载角色聚焦；方向键与视角手指独立，取消输入、窗口失焦、隐藏页面或调整视口会清理按住状态。桌面 WASD、鼠标和 Home 保留。

“画质优先”保留原有 DPR 上限 1.5、2048 阴影及环境遮蔽；“流畅优先”使用 DPR 上限 1、1024 阴影并关闭环境遮蔽。选择仅保存在本浏览器，存储不可用时仍可使用本次选择。切换不会更改素材或角色模型。

Chrome 本机视口回归覆盖 768×1024、1024×768、1024×540 和 600×1024，以及鼠标、键盘、地图、质量切换和角色点选。独立手指/取消/存储异常另有纯逻辑测试；这些不代表真实 iPad Safari、触屏或 GPU 性能已经验证。

### 一日邮差与本地存档

底栏“手记”提供“委托／见闻”两页。主线是问候→询问旧节拍→带回信，人物交接、回答和观察都由玩家主动操作；未加载、距离不足或地图/样板视图不能推进。地图查看保留原位置，顶部角色按钮继续可用。三封信可以在王城、三条旧街或入口样板找到对应人物，不强迫换街。

新进度键 `ff-garden.postal-journey.v2` 保存版本、章节、阶段及见闻ID。首次读取有效旧 `ff-garden.letter-quest.v1` 时先尝试备份，再映射到第一章；旧原始键始终保留。恢复与重置在“保存与恢复”中显式确认，先备份当前旅程；界面可以恢复最近一条旅程备份，内部安全记录最多三条。备份失败不替换进度，未知版本不覆盖。普通推进会核验其他页更新，避免旧页面按旧目标覆盖已发现的新进度；这不是跨设备或事务式多人存档。

玩法和恢复说明见[玩家指南](docs/POSTAL_PLAYER_GUIDE.md)。主线、迁移、恢复、故障、跨页与观察规则由 `npm run test:journey` 检查；王城路线、边界、角色可达性、地图范围及远景距离由 `npm run test:royal` 检查。浏览器QA以指定commit切片为证据，存储故障与真正iPad未测范围单独记录，不把逻辑检查当真实设备验收。
